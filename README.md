# 🧩 Redesign Homepage ONG CEPIS Juan Gabriel

Este projeto faz parte de uma atividade extensionista acadêmica focada em **Tecnologia Aplicada à Inclusão Social**. O objetivo principal do meu projeto foi revitalizar a interface (UI) e a experiência do usuário (UX) do site oficial da [ONG CEPIS Juan Gabriel](https://cepisjuangabriel.org.br/index.html), facilitando o acesso a informações sobre diagnóstico precoce de autismo em Macaé/RJ.

---

## 🚀 Sobre o Projeto

O site original foi analisado e reconstruído utilizando tecnologias modernas para garantir **performance**, **responsividade** e uma estética mais limpa e profissional.

### Melhorias Implementadas:
* **Slider Dinâmico:** Implementação de um banner principal com efeito *fade* (esmaecimento) inspirado no padrão industrial, mantendo o foco na mensagem principal.
* **Grid de Imagens:** Organização padronizada das fotos dos assistidos utilizando `object-fit: cover` para manter a proporção visual.
* **Navegação Fluida:** Sistema de *smooth scroll* para melhor usabilidade em dispositivos móveis.
* **Otimização de Código:** Migração de um construtor "drag-and-drop" para um código HTML5/CSS3 limpo e semântico.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização avançada, Flexbox e Grid.
* **JavaScript (ES6):** Lógica de navegação e interatividade.
* **[Swiper.js](https://swiperjs.com/):** Biblioteca para o carrossel de imagens responsivo.
* **Google Fonts:** Tipografia focada em legibilidade.

---

## 🎨 Identidade Visual

O projeto mantém o **Azul Institucional** da ONG, que transmite confiança e seriedade, combinado com elementos visuais coloridos que remetem ao universo lúdico da neurodiversidade.
